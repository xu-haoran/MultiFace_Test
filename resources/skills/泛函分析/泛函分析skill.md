## 知识卡：legacy-012 | 模块9.1：微分算子的形式伴随 / 模块9.1：微分算子的形式伴随
- 检索词：模块 微分算子的形式伴随 模块 微分算子的形式伴随
- 前提：仅用于下述正文明确列出的假设；若前提缺失，先补齐证明条件再应用。
- 公式与结论：
**核心概念：** 对 $L^2$ 上的微分算子 $L$，其形式伴随 $L^*$ 满足 $\langle Lf, g\rangle = \langle f, L^* g\rangle$（对所有紧支撑光滑函数 $f, g$）。由于试验函数紧支撑，所有边界项消失。

**散度型二阶算子的形式伴随：**

设 $L u = -\sum_{i,j} \partial_i (a_{ij} \partial_j u) + \sum_i b_i \partial_i u + c u$（$a_{ij}, b_i, c$ 为实值光滑函数），则：

1. **二阶项**：做两次分部积分把导数转移到测试函数上，形成「转置」结构。$\partial_i (a_{ij} \partial_j u)$ 转移后变为 $\partial_j (a_{ij} \partial_i g)$。
2. **一阶项**：做一次分部积分产生负号并把导数转移。$b_i \partial_i u$ 转移后变为 $-\partial_i (b_i g)$。
3. **零阶项**：保持自伴。$c u$ 转移后仍为 $c g$。

$$L^* g = -\sum_{i,j} \partial_j (a_{ij} \partial_i g) - \sum_i \partial_i (b_i g) + c g$$

**关键技巧**：
- 先写出伴随应满足的内积等式 $\langle Lu, g\rangle = \langle u, L^*g\rangle$，再逐项分部积分。
- 注意系数为实值光滑函数时，其位置（求导符号内或外）在转移中如何处理。
- 一阶项漏负号或导数转移方向写错是最常见的错误。
- 二阶项只分部积分一次（而非两次）会遗漏一层导数转移。

**考法提示**：竞赛或考试中常以「求某散度型算子的形式伴随」为题，要求写出 $L^*$ 的显式表达式。逐项处理时务必跟踪每一步的符号与导数转移方向。
