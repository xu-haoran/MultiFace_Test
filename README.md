# MultiFace 数学推理智能体

MultiFace 是面向数学竞赛题的多阶段推理 Agent。评测平台从仓库根目录加载
`user_agent.py`，注入官方 Client，并调用 `ReasoningAgent.solve(problem, metadata)`。

## 项目结构

```text
MultiFace/
├─ user_agent.py                 # 平台必需的根入口
├─ config.py                     # 模型、检索、温度和时间预算
├─ requirements.txt              # Python 依赖
├─ .gitignore                    # 本地缓存与日志忽略规则
├─ data/
│  └─ database/                  # Chroma 向量库及 HNSW 索引
├─ resources/
│  ├─ models/                    # Qwen3-Embedding-0.6B 等本地模型
│  └─ skills/                    # 数学领域技能文档与验证示例
└─ src/
   ├─ agent/                     # Agent 入口和总流程
   ├─ graph/                     # LangGraph 解题子图
   ├─ nodes/                     # 输入、分类、检索、推理、验证、协调节点
   ├─ state/                     # 跨节点状态定义
   ├─ mcp_servers/               # Python/SymPy 验证服务
   └─ utils/                     # 检索、答案整理、预算和日志工具
```

## 运行流程

1. 根入口加载 `src/` 并暴露平台要求的 `ReasoningAgent` 类。
2. Agent 初始化技能加载器、Python 验证服务和 Chroma 客户端。
3. 每题先输入处理和分类，再执行一次混合检索，将参考题目及解答缓存在本题状态中。知识卡直接从本地 `resources/skills` 选择，不查询向量集合。
   参考关系仅分为 `high_similarity`、`related`、`irrelevant`；没有稠密相似度的候选不注入提示词，稀疏得分仅参与召回与排序。
4. 按任务路由：数值、符号、搜索任务执行 Python；概念与术语题不因题号、选项编号或“方差”等名词触发程序。未知任务保守验证。概念题使用缓存知识来源进行短复核（90 秒节点上限），并记录引用和歧义。
5. 统一标准化候选和证据，再交叉验证。证据携带对象、关系、范围和候选标识，反驳题干的反例可支持“错误”；有限样本不作为全称验证。未验证的知识候选可参加来源复核，不能冒充 Python 共识。一致且完整的答案直接格式化；单分支失败或缺项只修复该分支；数学冲突复核双方，无法判定则仲裁。重试复用检索结果。
6. 协调器仅在答案缺失、缺项或缺证明过程时调用模型。完整候选直接输出，不再进行不影响答案的末尾参考解复核。
7. 最终提交节点检查答案格式和覆盖情况，`solve()` 返回非空 `final_response` 和可序列化 `trace`，包含验证策略、定向修复、提交检查及节点错误。

节点内的代码修复与模型传输重试仍保留；整题纠错受原有时间、Token 和轮次限制。最后五分钟仅用于收束与应急作答。完整性检查是题面启发式检查，不构成数学正确性证明。

生成程序统一定义无参数 `solve()` 或 `verify()`，返回 `answer`、`checks`、`evidence` 字典。系统先做 AST/编译检查，再由固定驱动调用、校验和打印；不猜测主函数，不要求模型补打印。明确的多项式参数列表误用可局部修复。推理先给答案区，再给过程区；模型提供的停止原因及 Token 用量保存在结果中，无法取得时记为未知。

## 离线流程验证

安装项目依赖后运行 `python -m unittest discover -s tests -v`。测试使用真实 LangGraph 和模拟解题节点，检查检索只执行一次、单分支修复、双方复核、按需验证、直接输出以及不完整填空拦截，不调用正式模型；流程使用模拟依赖，本地迁移验收会以只读方式检查数据库。

## 数据与模型

- `data/database/` 保存题目、解答和元数据，运行时只读检索。
- `resources/models/` 提供本地嵌入模型，向量检索不依赖互联网。
- `resources/skills/` 提供 18 个数学领域的完整本地知识卡与验证指南。按相关性选择整卡，超过预算时跳过整卡，禁止截断定理；卡片记录前提、公式、反例、记号、验证、来源及范围。历史例题和未核实教材口径存于 `data/skill_archive/`，不注入提示词。
- 大型数据库和模型文件按 Git LFS 规则管理。

## 提交约束

- 评测平台只加载根目录 `user_agent.py`，不需要修改调用方式。
- 所有资源路径均相对于项目目录解析，不依赖本机绝对路径。
- Client、密钥、限流和 Token 统计由平台注入，仓库不保存密钥。
- `trace` 记录分类、检索、推理、Python 验证和协调阶段的详细运行信息，便于本地诊断。

本地技能与向量知识卡迁移见 [实施与验收记录](docs/local_skill_migration_20261005.md)。
